# Image Prompt Pack: for the owner (free, highest quality)

**How to use (about 30–40 minutes, free):**
1. Open **gemini.google.com** (free account: about 20 images/day with Nano Banana 2). AI Studio at aistudio.google.com works too.
2. For each slot below, copy the whole prompt box, paste it into Gemini, and send.
3. If the result has strange hands, faces, eyes or any text or logos, click **regenerate** or say "try again, more natural hands".
4. Download the image you like (full size).
5. Rename it to the **file name** shown for the slot, e.g. `home-hero.png` (JPG is fine too).
6. Upload all of them to the repo folder **`design/images/inbox/`**. On GitHub: open the folder → **Add file → Upload files** → drag them in →
   **Commit directly to main**. The build agent checks this folder, reviews each image, crops, optimises and places it on the site.

Rules (honesty): these people are illustrative only. They'll never be labelled as Kuzikode staff, clients or testimonials.
